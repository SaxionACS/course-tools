### Examples

As a tutor, you **may** ask GenAI to:

- explain a concept, for example *"how does a hash table handle collisions?"*;
- explain an error message or a compiler warning;
- explain what a piece of code does — your own code included;
- point out, in words, why your approach does not work or where to look for a
  bug, without giving you corrected code;
- quiz you on the course material or give feedback on your understanding of it.

You may **not**:

- have GenAI write, complete or fix (part of) your solution — also not by
  copying or retyping code or text from its answers;
- use AI code completion in your editor, such as GitHub Copilot, JetBrains AI
  Assistant or Cursor — switch it off while you work on these assignments;
- have GenAI write or rewrite text that you hand in, such as a report, a README
  or code comments;
- generate tests, test data, diagrams or designs with GenAI.

If an explanation contains example code, use it to understand the idea. Then
close it, and write your own solution without looking at it.

Be open about it: if you used GenAI as a tutor for an assignment, add a short
`GENAI.md` to your submission that says which tool you used and what you asked
it about. You do not need to include the prompts and answers.
